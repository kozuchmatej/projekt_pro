# Todo List aplikácia

Jednoduchá webová aplikácia vytvorená v PHP s využitím databázy MySQL (mysqli).

## Funkcie aplikácie

- pridanie úlohy
- zobrazenie úloh
- označenie úlohy ako hotovej
- vymazanie úlohy

Aplikácia využíva CRUD operácie:
- Create
- Read
- Update
- Delete

## Použité technológie

- PHP
- MySQL
- mysqli
- HTML
- Bootstrap 5

## Databáza

Projekt obsahuje databázu:

`todo_app`

Tabuľky:
- users
- tasks
